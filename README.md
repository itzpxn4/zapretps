# zapretps
Создан из личного удобства, автоматом открывает запрет через терминал на второй рабочий стол + удобная настройка

## Установка / Настройка
1. После скачивания, расположите, где удобно и в .ps1 файле, в 10й строке, поменяйте $basePath на путь до папки запрета:
```powershell
$basePath = "C:\PLACE\YOUR\PATH\HERE\zapret-discord-youtube-1.9.8b"
```
2. Поменяйте стратегию на нужную
```powershell
$strategy = "general (ALT3).bat"
```
3. Перейдите в терминал, и зайдите в профиль powershell'a
```powershell
ii $PROFILE
```
4. Открывается ISE, в нее надо вставить
```powershell
function zt {& "C:\PATH\FOR\ZAPRETPS\FILE\idk.ps1" @args}
```
5. Поменять путь в функции, он должен вести к .ps1 файлу, можно так же переименовать функцию
6. Перезапустить терминал и использовать
```powershell
zt -h
```
7. Должен получится этот список
```powershell
-help    : Этот список
-folder  : Папка запрета
-list    : Список сайтов
-config  : Скрипт
```
